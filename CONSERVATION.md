## Как поднять обратно

**Стенд:**
```bash
ssh root@tgp.isgood.host
cd /opt/tg-poker
mv /root/tgp-backup.cron.disabled /etc/cron.d/tgp-backup
bash update.sh            # подтянет main, соберёт и поднимет контейнеры
certbot renew             # если сертификат успел истечь
```

**Боевая машина** собирается заново с нуля — фаза A `plans/mainnet-cutover-plan.md`
и `DEPLOY.md`: новый VPS, A-запись `nightriver.isgood.host`, SSL, новые секреты
(`POSTGRES_PASSWORD`, `JWT_SECRET`, `ADMIN_PASS`), `BACKUP_REMOTE=b2:tgp-backups/prod`.
`CRYPTO_PAY_TOKEN` и `BOT_TOKEN` взять из менеджера паролей. Дальше — фаза E
(депозит $5 → вывод $10 → инвариант `✓ balanced`), и только потом пускать игроков.
